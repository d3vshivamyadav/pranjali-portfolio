## 🎯 Overview

This portfolio website showcases Pranjali Yadav's skills, projects, and professional journey as a BCA final year student. The design draws inspiration from **Google's Material Design**, **Apple**, **Vercel**, and modern developer portfolios, combining aesthetics with functionality.

### Key Highlights

- ✅ **100% Pure Code** — No frameworks, no dependencies
- ✅ **Material Design** — Rounded cards, soft shadows, modern spacing
- ✅ **Glassmorphism** — Frosted glass effects with backdrop blur
- ✅ **Dark/Light Mode** — Seamless theme switching with local storage
- ✅ **Fully Responsive** — Desktop, laptop, tablet, and mobile
- ✅ **Premium Animations** — Smooth transitions, scroll reveals, typing effects
- ✅ **Accessibility** — ARIA labels, keyboard navigation, semantic HTML

## 🚀 Features

### Core Features

| Feature | Description |
|---------|-------------|
| **Sticky Navbar** | Fixed navigation with active state tracking |
| **Hero Section** | Large heading with typing animation and profile image |
| **Typing Animation** | Dynamic text rotation in the hero section |
| **Download Resume** | One-click resume download button |
| **Social Icons** | LinkedIn, GitHub, Instagram, Twitter |
| **Featured Projects** | Preview of top projects on the homepage |
| **Skills Preview** | Tech stack badges with hover effects |
| **Call to Action** | Prominent CTA sections throughout |
| **Footer** | Complete footer with navigation and contact info |

### Page-Specific Features

- **About Page** — Professional introduction, career objective, education timeline, achievements, languages, hobbies, personal information
- **Skills Page** — Animated skill bars with percentage indicators, circular progress for soft skills
- **Projects Page** — Filterable project cards, hover effects, modal popups, GitHub and Live Demo buttons
- **Contact Page** — Responsive contact form with validation, social links, address info, Google Map embed
